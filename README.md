# 🛒 Zepto Inventory Analysis using SQL

## 📌 Project Overview
This project analyzes the Zepto Inventory Dataset using SQL. The objective is to explore product availability, pricing, discounts, inventory levels, and category-wise performance while demonstrating practical SQL skills used in retail analytics.

The project includes data cleaning, exploratory data analysis (EDA), and business-oriented SQL queries to generate actionable insights from inventory data.

## 🎯 Business Objectives
Analyze product inventory across categories.
Identify out-of-stock products.
Evaluate discount strategies.
Calculate category-wise estimated revenue.
Measure inventory weight distribution.
Identify high-value and high-discount products.

## 🛠️ Tools & Technologies
PostgreSQL
SQL
CSV Dataset

## 📂 Dataset

The dataset contains inventory information for products available on Zepto, including:
Product Name
Category
MRP
Discount Percentage
Selling Price
Available Quantity
Weight
Stock Status

## 🧹 Data Cleaning

The following cleaning steps were performed:
Removed products with zero MRP.
Converted prices from paise to rupees.
Checked for missing values.
Identified duplicate product names.

## 📊 SQL Analysis Performed
Total number of products
Product categories
Stock vs Out-of-Stock analysis
Duplicate product detection
Highest discount products
Premium products currently unavailable
Category-wise estimated revenue
High-value products with low discounts
Average discount by category
Price per gram analysis
Product weight classification
Total inventory weight by category

## 📈 Key Business Insights
Identified categories offering the highest average discounts.
Estimated revenue contribution for each product category.
Detected premium products that were unavailable.
Compared pricing efficiency using price-per-gram analysis.
Classified products into Low, Medium, and Bulk weight segments.
